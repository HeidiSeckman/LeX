# ✦ LeX — Next-Gen Social Architecture

**Powered by LexiTech Studio // Founded & Engineered by Heidi Seckman (Est. 2026)**

LeX brings back the soul of classic customizable social spaces—personal profile skins, ranked Top 8 friends, and profile theme anthems—reimagined inside LexiTech Studio's signature obsidian-and-magenta architecture with zero engagement algorithms and a mandatory **13+ age verification gate**.

---

## ✨ Core Features

- **13+ Age-Verified Onboarding & Custom `@handle` Creator:** Requires date-of-birth verification (13+ only) and lets members claim their personal `@handle` and display name.
- **Live "Vibe-Sync" Profile Rooms:** Visitors hear your active Profile Anthem in real time alongside an ephemeral live room chat.
- **Procedural Profile Anthem Player:** Built-in, zero-copyright WAV synthesizer tracks (*Y2K Cobalt Synth*, *Midnight Tokyo Lo-Fi*, *Velvet Chrome Rhodes*, *Neon Arcade Pulse*).
- **Profile Studio & AI Vibe Remix:** Opens in official **LexiTech Obsidian & Magenta**, while letting users remix their personal profile skin via prompt or curated presets.
- **Interactive Top 8 Friends & Inner Circle Radar:** Rank your inner circle with one-click reordering and view live online moods and playing tracks with zero public follower counts or ads.

   ```bash

   ```

   ```bash
   streamlit run app.py
   ```
